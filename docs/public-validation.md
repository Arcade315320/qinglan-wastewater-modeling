# 公开数据复核记录

## 截图问题复现

截图录入值为：化学需氧量 260、氨氮 32、总氮 48、总磷 4.2、
悬浮物 12 毫克/升。原自动组分化重构出的悬浮物约为 118.8 毫克/升，
相对偏差约 890%，因此可信度检查未通过。该组合很可能把出水悬浮物填入了
进水栏。

修正措施：

- 进水悬浮物与化学需氧量比值低于 0.08 时，在计算前拦截并要求复核。
- 自动组分化同时约束化学需氧量、悬浮物，并在可行范围内逼近总氮和总磷。
- 结果页分别显示水力闭合、组分重构、表观回收和稳态状态。
- 表观回收数值容差统一为 103%，避免将 0.01% 量级的积分误差误判为失败。

将进水悬浮物修正为 180 毫克/升后，50 天计算得到：

| 项目 | 结果 |
| --- | --- |
| 预测化学需氧量 | 17.486 毫克/升 |
| 预测氨氮 | 0.082 毫克/升 |
| 预测总氮 | 14.349 毫克/升 |
| 预测总磷 | 2.898 毫克/升 |
| 预测悬浮物 | 11.073 毫克/升 |
| 组分重构最大偏差 | 10.94% |
| 水力与表观回收检查 | 通过 |
| 50 天末端稳态判定 | 未达到 |

总磷和悬浮物仍超过页面采用的 0.5、10 毫克/升限值，属于当前工艺模型的
预测结果，不应通过修改判定逻辑强行改成达标。

## 后续校准要求

1. 增加化学除磷药剂、外加碳源和三级过滤单元。
2. 录入实际池容、分区、回流位置、排泥量、二沉池面积及污泥沉降参数。
3. 补充可溶性/颗粒性化学需氧量、挥发性脂肪酸、正磷酸盐、硝态氮等组分。
4. 使用同一污水厂至少五组按日期配对的进出水数据校准，并保留独立验证时段。
5. 超过 50 天的动态积分改为异步任务，避免同步网页请求超时。
