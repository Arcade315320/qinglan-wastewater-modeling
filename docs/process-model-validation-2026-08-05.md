# 污水工艺模型验证记录（2026-08-05）

## 验证原则

- “接口可提交”“动态积分收敛”“质量守恒通过”和“实厂误差合格”分别判定。
- 未建立专用反应器、回流、固液分离或膜单元的工艺必须阻止计算，不能套用连续流活性污泥模型后宣称准确。
- 实厂准确性要求使用同一工厂、同一时段的进水、运行参数和出水数据；论文未公开的参数必须标记为估算。
- 当前建议的单指标验收线为归一化误差不高于20%，且独立验证样本不少于两条。

## 已执行的数值验证

### 基准模型一固定回归

- 基准出水：化学需氧量47.552、氨氮1.735、总氮14.044、悬浮物12.497毫克/升。
- 程序结果处于0.5%回归容差内，动态收敛、质量守恒和计算引擎检查通过。
- 此项是标准基准回归，不是实际工厂独立验证。

### 沈阳全规模厌氧—缺氧—好氧污水厂

- 公开夏季均值：进水化学需氧量161.58、氨氮21.62毫克/升；去除率分别为81.6%和86.5%。
- 对应实测出水推算值：化学需氧量29.731、氨氮2.919毫克/升。
- 当前模型预测：化学需氧量18.518、氨氮0.089毫克/升。
- 相对误差：化学需氧量37.7%，氨氮97.0%，不通过20%准确性门槛。
- 动态积分在60天收敛且质量守恒通过，说明问题属于组分与动力学校准，不是求解器失效。
- 数据来源：https://journals.sagepub.com/doi/full/10.1089/ees.2018.0280

### 台北全规模分段进水缺氧—好氧污水厂

- 论文提供连续一年12组进出水和运行均值。
- 当前程序只有单点进水缺氧—好氧拓扑，不能把该厂分段进水结果作为已通过验证。
- 数据来源：https://link.springer.com/article/10.1186/s42834-020-00064-6

## 当前结论

现阶段只有三种工艺具备动态计算入口；其中基准回归通过，但尚无一种同时具备完整同厂参数、校准数据和独立验证数据而达到工程复核条件。其余工艺被正确阻止。后续应按真实项目优先级逐个建立专用模型，而不是同时用近似公式开放全部工艺。
